## 🎯 What This Repository Contains

This is a **living framework** that defines how our team writes, reviews, tests, and ships code.

It is intentionally **lightweight** — built for a 6-person team that needs to move fast without sacrificing quality.

## 🧭 Guiding Principles

1. **Automate before you mandate** — a rule a machine enforces beats ten rules in a wiki.
2. **Block what's cheap to fix, warn on what's expensive.**
3. **The author owns quality** — reviewers verify, they don't substitute for diligence.
4. **Tests are documentation** — a good test explains what code is supposed to do.
5. **This is v1** — it will be wrong in places. We fix it as we learn.
